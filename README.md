# 按键时间线记录器

一个用于记录和可视化按键时间线的小工具。

## 功能特点

- 🎹 **按键记录** - 按下快捷键后开始记录所有按键
- ⏱️ **时间轴显示** - 可视化展示按键的时间分布
- 🔢 **次数统计** - 自动统计重复按键的次数
- 📊 **实时更新** - 记录过程中实时显示数据
- 💾 **数据导出** - 支持导出为 JSON 格式

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

1. 运行程序：
   ```bash
   python key_timeline_recorder.py
   ```

2. 开始记录：
   - 按 `Ctrl+Alt+R` 快捷键，或点击"开始记录"按钮

3. 按下你要记录的按键

4. 停止记录：
   - 再次按 `Ctrl+Alt+R`，或点击"停止记录"按钮

5. 查看结果：
   - 上方时间线显示按键的时间分布
   - 下方表格显示详细的按键信息（序号、按键、时间、相对时间、次数）

6. 其他功能：
   - 点击"清除"按钮清空当前数据
   - 点击"导出JSON"按钮保存记录数据

## 界面说明

- **控制面板**：显示记录状态，包含开始/停止、清除、导出按钮
- **时间线**：可视化显示每个按键的时间位置，相同按键用同色圆点表示
- **详情表格**：列出所有按键事件的详细信息

## 注意事项

- 在 Windows 上可能需要以管理员身份运行才能正常监听全局按键
- 快捷键 `Ctrl+Alt+R` 用于切换记录状态
- 按键计数的含义：该按键在整个记录过程中被按下的总次数
